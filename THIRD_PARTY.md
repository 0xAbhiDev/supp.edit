The application uses original source code and UI styling. It does not include Adobe code, branding, assets, fonts, or proprietary project formats. Typography uses system generic families. Lucide provides open-source icons; the supp.edit mark is an original SVG.

`setup:media` is an explicit local developer convenience and downloads external binaries from the [Gyan Windows provider](https://www.gyan.dev/ffmpeg/builds/) linked by [FFmpeg](https://ffmpeg.org/download.html), checking its published SHA-256. It is not a license grant for commercial redistribution. The supplied application executable does not embed FFmpeg, codec binaries, AI models or fonts. Patent and codec licensing vary by deployment. Review the precise FFmpeg configuration, corresponding-source obligations and codec distribution rights before packaging a professional release. No conclusion about legal clearance is implied by this engineering inventory.

Package-lock.json and Cargo.lock pin the resolved dependency graph. Dependency audit results for this build are recorded in docs/VALIDATION.md. A production release still needs a full transitive license audit, vulnerability triage, platform signing and an SBOM. Refer to [FFmpeg's licensing page](https://ffmpeg.org/legal.html) and [FFprobe documentation](https://ffmpeg.org/ffprobe.html) for the media integration.

Local speech setup explicitly downloads the [whisper.cpp b5454 CPU runtime](https://github.com/ggml-org/whisper.cpp/releases/tag/b5454) (MIT) and the [Tiny converted weights](https://huggingface.co/ggerganov/whisper.cpp) from the upstream Whisper family. Runtime/model files remain outside source and executable bundles. Native downloads use reqwest/rustls; SHA-256 uses sha2; ZIP extraction uses zip. Resolved licenses are recorded in their Cargo manifests. The installer verifies pinned hashes and sizes; no media is sent to either download host.

Local vision setup explicitly downloads [MobileCLIP-S0](https://huggingface.co/Xenova/mobileclip_s0/tree/757d59c9c6870a76a4b0306f05f5061bca15c39f) image/text/tokenizer artifacts, [YOLOX Nano](https://github.com/Megvii-BaseDetection/YOLOX/releases/tag/0.1.1rc0) and [ONNX Runtime 1.31.1](https://github.com/microsoft/onnxruntime/releases/tag/v1.31.1). MobileCLIP's supplied Apple license permits use, reproduction, modification and redistribution subject to retaining its notices; it is **not labeled MIT**. Its exact license and YOLOX's Apache-2.0 license are downloaded and retained with the weights; the runtime archive retains Microsoft notices. The app/source bundle contains no model weights. Native bindings use ort (MIT/Apache-2.0), tokenizers (Apache-2.0), and image (MIT/Apache-2.0). See docs/VISION_VALIDATION.md for artifact versions, fixture attribution and limitations.
