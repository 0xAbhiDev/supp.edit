# Project format v5

`.supp` and `.suppedit` contain UTF-8 JSON. New saves use `schemaVersion: 5`. Both readers accept v1, v2, v3, v4 and v5 and reject newer versions. Migration copies the input, fills identity axis scales/zero anchors/zero crop and empty new channels, and advances the in-memory version. Reading never rewrites the source file. Migration also fills empty compositions and transcripts. Shared fixtures cover legacy versions and the current version.

Root fields: `id`, `name`, `createdAt`, `modifiedAt` (UTC ISO timestamps), `settings`, `assets`, `tracks`, `clips`, `markers`, `compositions`, `transcripts`. Settings store width/height, `{num, den}` FPS, and `colorSpace: "srgb"`.

All timeline positions and durations are **integer project frames**. Rational rate conversion happens at media boundaries; source time = `(sourceIn + timelineFrame - clip.start) * fps.den / fps.num`. Timecode labels are non-drop-frame, including at 29.97 / 59.94. VFR sources are sought by timestamp through the webview.

Assets contain original local paths, metadata, a UUID, and a lightweight fingerprint (path/name + size + modification time). Fingerprints are duplicate heuristics, not content hashes. Browser blobs are stored separately in IndexedDB under the asset UUID. Portable browser project files need source relinking outside the original browser.

Tracks define ordering, kind, lock, visibility, mute, and solo. Video tracks higher in the list composite above lower tracks. Within one track, later clips in graph order composite above earlier overlapping clips. Audio tracks accept audio assets only; video clips retain their linked original audio. This release has no unlink operation.

Clips define asset references or generated text/shape content, timeline placement, source offset, gain (dB), transform, color/blur parameters, mask, and keyframes. Transform position is in project pixels relative to canvas center. Uniform scale multiplies `scaleX` and `scaleY`. Anchors are pixel offsets from layer center; the local anchor is subtracted before axis scaling, rotation and translation. Opacity is 0–1. The legacy mask field retains normalized rectangles/ellipses. The masks array adds ordered closed cubic paths in the same local composition coordinate system.

Animation channels: x, y, scale, scaleX, scaleY, rotation, anchorX, anchorY, opacity, blur, brightness, contrast, saturation, cropLeft, cropTop, cropRight, cropBottom. Keys contain a relative integer frame, numeric value, outgoing interpolation (`linear`, `hold`, `ease-in`, `ease-out`, `ease-in-out`, `bezier`, `auto-bezier`, `continuous-bezier`) and optional `inHandle` / `outHandle` objects. Handle x is a nonnegative fraction of the adjacent time interval, y a signed value offset. If adjacent x handles overlap, their sum is normalized to one. Evaluation inverts cubic time with bounded bisection. Auto uses monotone weighted harmonic tangents and zero endpoint slopes. Continuous links the edited key’s opposite tangent in value/frame space. Curves may overshoot, but rendered properties clamp to their declared domains. Speed graphs show signed value units per second; Hold discontinuities have no finite velocity. Negative and beyond-end keyframe times are deliberately retained after splitting/trimming to preserve eased interpolation exactly. Inspector rows show keys inside the clip. These out-of-range keys are not invalid data.

Native validation caps project files at 64 MiB on read and rejects duplicate IDs, missing references, incompatible track kinds, invalid values and source overruns. The TypeScript and Rust models share fixtures in `tests/fixtures/project.supp` and `tests/fixtures/animation.supp`; keep both schemas synchronized.

Save writes a sibling temporary file, flushes it, and atomically replaces the destination. A previous-save `.supp.bak` is kept. Native autosave rotates five independent recovery JSON files in the app data directory. Recovery opens as unsaved and requests a new save location so a recovery file cannot smuggle a write destination. Project files do not embed thumbnails, decoded frames or media buffers.

Crop edges are normalized in the same project-sized local coordinate system as existing masks, applied after transform/effects clipping in both backends. Opposite crop sums of one or more produce an empty region. Crop is not a destructive source resize. The renderer resolves all animated channels once per layer and frame through `packages/animation`, shared with export. Photo, blend and effect-stack fields remain deferred.

## Composition and transcript additions

A Composition has globally unique id, name, settings, duration, background (transparent or hex RGB), tracks and layers. Clips of kind composition reference compositionId; null clips render no pixels. Child timing uses (parentFrame - start + sourceIn) / parentFPS * childFPS, retaining fractional frames. Source-in and clip duration are in the containing scope's frame rate. Cycles, missing sources and source overruns fail validation. Limits: 64 definitions, 16 levels, 100,000 layers total; rendering adds expansion/memory budgets.

Transcripts contain id, name, source (srt or transcription), optional language/assetId and ordered segments with id, startMs, endMs and text. Timestamps are integer milliseconds. SRT captions persist ordinary text clips and a caption track in the main sequence. No media buffers, AI model files, job state, provider credentials or cloud-consent tokens belong in project JSON. See ../AI_ARCHITECTURE.md for safe execution contracts.

Parenting: optional parentId names a visual clip in the same scope. parentOffset defaults to [1,0,0,1,0,0] and is a finite affine matrix with each component bounded to ±1e9. The matrix preserves shear when reparenting/unparenting. Maximum 64 parent links, with cycles/self/missing/cross-scope/audio parents rejected. Parent opacity/visibility/effects are independent of children.

Bezier masks (v5): masks defaults to []. Each mask stores id/name/enabled/mode/inverted/closed, 3–128 vertices, opacity 0–1, feather 0–256 px and expansion −512–512 px. Vertices have stable IDs, x/y coordinates −4…5, and relative in/out tangents −8…8. Up to 32 masks per visual layer; Null/audio layers cannot have masks. Each mask owns opacity/feather/expansion scalar channels (up to 1,000 keys each) and up to 128 path keys with linear/hold interpolation. Frames are relative to clip start and can be negative for trim/split preservation. Every path key must retain the base vertex IDs/order/count. Duplicate mask IDs within a clip, duplicate vertex IDs and duplicate key times fail validation.
